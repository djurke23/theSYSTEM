# SYSTEM: Awakening | Solo Leveling Gamified Fitness Tracker

> **"Wake Up, Hunter. The System Has Chosen You."**

An elite, immersive, responsive dark-mode landing page and web interface for **SYSTEM: Awakening**, inspired by the world of the *Solo Leveling* anime and manhwa.

---

## ⚡ Key Highlights & Features

- **Dark Mode Anime Aesthetics**: Abyss blue-black background (`#030712`, `#050A14`), Electric Cyan mana glows, Monarch Gold, Emergency Crimson, and Shadow Purple accents.
- **Holographic System Modal**: Interactive Quest Arrival dialog with Reawakening acceptance and penalty overrides.
- **System HUD Status Window**:
  - Interactive Paperdoll with Player Level, Class (*Shadow Monarch*), Title, and HP/MP gauge bars.
  - Interactive Core Attribute Distributor (STR, VIT, AGI, INT, SENSE) with real-time Combat Power recalculations.
  - Equipment Slot Inspector (Kasaka's Poison Fang, Demon King's Longsword, High Knight Plate, Orb of Avarice).
- **Interactive Hunter Rank Evaluation & Animated License Card**:
  - Calculate Hunter Rank (E to S) based on max push-ups and 5K run benchmarks.
  - 3D Interactive Parallax Tilt card with dynamic rank emblem and certification barcode.
- **Bento Feature Grid**:
  - **Feature A**: Real-time on-device TensorFlow.js AI Camera Rep Vision with "Shadow Scanner Mode" and live combat damage simulator.
  - **Feature B**: Real-world GPS Gates and Fog of War interactive radar scope.
  - **Feature C**: "ARISE!" voice command shadow soldier extraction and passive AFK mining.
  - **Feature D**: Daily Quest countdown timer and interactive Penalty Zone desert alert simulation.
  - **Feature E**: 15 Canonical Manhwa Story Chapters.
  - **Feature F**: Anatomical Muscular Heatmap recovery analytics and hydration/sleep tracker.
- **Hunter Player Logs**: Cyberpunk terminal CRT interface displaying verified telemetry logs.
- **Accessible Accordion FAQ**: Search-friendly native `<details>` implementation.
- **Dedicated Legal Pages**:
  - `privacy.html`: Comprehensive Security & Privacy Protocol (100% on-device vision, zero cloud frame caching, GPS obfuscation).
  - `terms.html`: Terms of Service, mandatory physical fitness medical disclaimer, real-world exploration safety, and fair-use tribute notice.
- **Zero-Dependency Web Audio API Sound Synthesizer**: In-browser sound effects (System Chime, Stat Point Ding, Arise Sub-Bass Shockwave, Hunter Rank Fanfare, and Penalty Siren) with nav bar SFX toggle.
- **Collapsible Floating Quest Tracker**: Fixed bottom-right HUD widget tracking real-time user discovery progress with minimize/expand controls.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup.
- **CSS3**: Custom design tokens, glassmorphism, responsive Bento Grid, scanlines, and CSS animations.
- **JavaScript (Vanilla ES6+)**: Interactive state management, Web Audio API synthesis, and 3D card tilt.
- **Lucide Icons**: Crisp vector UI icons.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or run a local static server:

```bash
# Using Python
python3 -m http.server 8000

# Using Node.js
npx serve .
```
